# 11. Glossaire {#glossaire}

## Mots de l'application {#glossaire-mots}

| Mot | Sens |
| --- | --- |
| Affiche | Page A4 à imprimer avec le QR code du site et trois consignes. |
| Archives | Dossiers clôturés, classés sans suite ou rattachés à un doublon. |
| Atelier | Écran de travail d'un plan de bâtiment déjà créé. |
| Brouillon | Modifications d'un plan gardées sur l'appareil tant qu'elles ne sont pas enregistrées. |
| Calibration | Réglage de l'échelle d'un fond de plan à partir d'une longueur connue. |
| Calque | Contour du niveau inférieur affiché en pointillés sous le plan. |
| Classement ERP | Type et catégorie d'établissement recevant du public, déclarés pour un bâtiment. |
| Composant | Élément de l'inventaire : équipement, élément du bâti, matériel. |
| Contrôle | Saisie de ce qui a été fait à une échéance préventive. |
| Corps d'état | Famille technique d'un composant : électricité, couverture, mobilier… |
| Cote | Longueur mesurée entre deux points du plan. Cote de contrôle : longueur mesurée sur place, pour vérifier l'échelle. |
| Couverture | Part des composants actifs qui ont au moins une évaluation. |
| Danger | Situation dangereuse pour les personnes ou le bâtiment, signalée à part de la priorité. |
| Déclarant | Personne qui a signalé le problème, avec ou sans compte. |
| Délégué | Membre qui a les mêmes droits que le responsable sur un site. |
| Dossier | Suivi d'un problème ou d'une demande, de la déclaration à la clôture. |
| Doublon | Dossier qui décrit le même problème qu'un dossier déjà ouvert. |
| Échéance | Date à laquelle le prochain contrôle d'un plan préventif est attendu. |
| État final | Résultat d'une intervention : Résolu, Mesure provisoire, Non résolu. |
| Évaluation | Note de l'état d'un composant à une date, sur l'échelle commune. |
| Fond de plan | Image ou page de PDF qui sert de base au dessin d'un plan. |
| Fraîcheur | Part de la note qui repose sur des évaluations de plus de 6 mois. |
| Grille | Liste des points à observer et des mesures pour un corps d'état. |
| Intervention | Travail confié à un technicien ou à un prestataire dans un dossier. |
| Lot | Plusieurs objets identiques suivis ensemble, avec une quantité. |
| Niveau | Étage d'un bâtiment (sous-sol, rez-de-chaussée, tribune…). |
| Organisation | Votre église ou votre réseau d'églises dans l'application. |
| Parties communes | Zone créée avec chaque bâtiment, pour ce qui sert à tout le bâtiment. |
| Plan de bâtiment | Dessin d'un niveau, à l'échelle. |
| Plan préventif | Entretien ou vérification à refaire à intervalles réguliers. |
| Prestataire | Entreprise extérieure, sans compte, suivie par un référent interne. |
| Priorité | Urgente, Haute, Normale ou Basse ; fixe les délais. |
| Qualifier | Fixer la priorité et la zone d'un dossier. |
| Référent interne | Membre du site qui suit le travail d'un prestataire. |
| Réserves | Écarts d'un contrôle qui restent à traiter par des dossiers. |
| Site | Lieu géographique de l'organisation : une église, un centre. |
| Version | État enregistré d'une grille ou d'un plan ; les versions passées sont conservées. |
| Zone | Pièce ou espace d'un bâtiment. |

## Sigles {#glossaire-sigles}

| Sigle | Sens |
| --- | --- |
| BAES | Bloc autonome d'éclairage de sécurité. |
| DAE | Défibrillateur automatisé externe. |
| ERP | Établissement recevant du public. Le type V désigne les lieux de culte. |
| PDF | Format de document à imprimer ou à archiver. |
| QR code | Code carré à scanner avec l'appareil photo d'un téléphone. |
| SDIS | Service départemental d'incendie et de secours. |
